# MedReg Radar · 医疗器械法规雷达

医疗器械的法规和政策更新得快：注册与备案、分类目录、行业标准、召回与不良事件、集中采购、设备更新……文件分散在多个部门的网站上，一线的设备工程师、采购和管理人员很难及时跟上。

**MedReg Radar 定期把公开发布的文件收拢到一处，按"影像设备 / 医疗器械 / 背景"分级，配上 AI 解读、数据图表和 AI 问答，生成周报、月报和一个可以直接分享的网页。** 第一版聚焦医学影像设备（CT、MR、DR、DSA、超声、核医学、放疗等），其他器械作为背景简要列出。

## 给不同的人

| 你是 | 怎么用 |
|---|---|
| 只想看结果 | 打开项目网页（GitHub Pages），或者看 `reports/` 里的周报、月报。不需要安装任何东西。 |
| 想自己跑一份 | 下载本项目，双击 `运行雷达.command`（Mac），或运行 `python3 radar.py`。只需要 Python 3.8+，不用装第三方库。 |
| 想改成自己的领域 | 改 `config.json` 里的搜索词和关键词即可，比如换成"体外诊断"或"康复器械"。 |

## 数据从哪来

| 来源 | 方式 |
|---|---|
| 中国政府网 · 政策文件库 | 自动抓取。使用网站自身的公开搜索接口，低频访问，每次请求间隔 2 秒。 |
| 国家药监局 · 医疗器械公告与法规 | **手动导入。** 该网站不允许程序访问，本项目尊重这一点，不做任何绕过。由人在浏览器里正常打开页面并保存，程序负责后续处理。见 [导入指南](导入指南.md)。 |

## 网页上有什么

- **雷达**：每个点是一份新文件，越靠近中心越和影像设备相关。悬停看标题，点击看原文。
- **动态**：按时间、分级、关键词筛选；每条附官方原文链接，有 AI 解读的会一并显示。
- **数据**：历年政策文件数、药监局每月批准注册的产品数、主题分布、近 12 个月收录量。每张图都能切换成表格。
- **问 AI**：只根据本站收录的文件回答，并标出出处编号。访客使用**自己的** DeepSeek API key：key 只存在访客自己的浏览器里，直接发给 DeepSeek，不经过任何服务器，本仓库里也没有任何 key。

## AI 解读（可选）

在本地运行时，雷达可以用你自己的 DeepSeek API key 给每条新文件写一段三句话的解读（讲了什么、影响谁、和影像设备的关系），写好的解读随数据一起发布，访客无需 key 即可阅读。

- **Mac**：双击 `填写AI密钥.command`，粘贴 key 回车即可。key 存在 `.secrets/deepseek_key.txt`，该文件夹已被 `.gitignore` 排除。
- **其他方式**：设置环境变量 `DEEPSEEK_API_KEY`；在 GitHub 上则添加名为 `DEEPSEEK_API_KEY` 的 Actions secret。
- 没有 key 时自动跳过，其余功能照常。只有标题、没有正文的条目（如药监局公告），解读会标注"仅据标题"。
- 模型和接口地址写在 `config.json` 的 `ai` 一节，兼容 OpenAI 接口格式的服务都可以替换。

## 它怎么工作

```
抓取 / 手动导入 → 关键词分级（影像设备 > 医疗器械 > 背景）+ 主题标签 → 去重存档 → AI 解读（可选）→ 周报 · 月报 · 网页
```

- 分级和标签规则全部写在 `config.json`，可以直接改。
- 所有条目存在 `data/items.json`，周报和月报只是同一份数据的不同时间窗口。
- `.github/workflows/radar.yml` 让 GitHub 每周一自动运行一次自动抓取部分，并更新网页。

## 目录

```
radar.py            主程序
config.json         搜索词、关键词、标签规则
medreg/             抓取、导入、分级、AI 解读、报告、网页
medreg/web/         网页的样式、脚本和模板
inbox/              手动保存的网页放这里
data/items.json     全部条目
reports/            周报 weekly/、月报 monthly/（Markdown）
docs/               网页（GitHub Pages 从这里发布）
```

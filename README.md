# MedReg Radar · 医疗器械法规雷达

医疗器械的法规和政策更新得快：注册与备案、分类目录、行业标准、召回与不良事件、集中采购、设备更新……文件分散在多个部门的网站上，一线的设备工程师、采购和管理人员很难及时跟上。

**MedReg Radar 定期把公开发布的文件收拢到一处，按"影像设备 / 医疗器械 / 背景"分级，配上数据图表，生成周报、月报和一个可以直接分享的网页；筛选出的内容可以一键导出，交给你常用的 AI 继续分析。** 第一版聚焦医学影像设备（CT、MR、DR、DSA、超声、核医学、放疗等），其他器械作为背景简要列出。

## 给不同的人

| 你是 | 怎么用 |
|---|---|
| 只想看结果 | 打开项目网页（GitHub Pages），或者看 `reports/` 里的周报、月报。不需要安装任何东西。 |
| 想自己跑一份 | 下载本项目，双击 `运行雷达.command`（Mac），或运行 `python3 radar.py`。只需要 Python 3.8+，不用装第三方库。 |
| 想改成自己的领域 | 改 `config.json` 里的搜索词和关键词即可，比如换成"体外诊断"或"康复器械"。 |

## 数据从哪来

| 来源 | 方式 |
|---|---|
| 中国政府网 · 政策文件库 | 自动抓取。使用网站自身的公开搜索接口，低频访问，每次请求间隔 2 秒。 |
| 国家药监局 · 医疗器械公告与法规 | **手动导入。** 该网站不允许程序访问，本项目尊重这一点，不做任何绕过。由人在浏览器里正常打开页面并保存，程序负责后续处理。见 [导入指南](导入指南.md)。 |

## 网页上有什么

- **雷达**：每个点是一份新文件，越靠近中心越和影像设备相关。悬停看标题，点击看原文。
- **动态**：按时间、分级、关键词筛选；每条附官方原文链接。
- **数据**：历年政策文件数、药监局每月批准注册的产品数、主题分布、近 12 个月收录量。每张图都能切换成表格。
- **导出给 AI**：把筛选出来的内容连同一段任务指令（总结变化、对设备科工程师的影响、调研报告大纲……）一键复制，粘进豆包、DeepSeek、Kimi 等任意聊天 App；手机上可直接分享到 App；也可下载 `.md`（上传给 AI）或 `.csv`（用 Excel 打开）。

本项目本身不调用任何 AI 服务，也不需要任何 API key。分析交给使用者自己选择的 AI 或智能体。

## 给智能体用

完整数据以 JSON 公开在网页同目录下的 `data.json`（GitHub Pages 地址 + `/data.json`），字段：`url`、`title`、`date`、`source`、`doc_no`、`level`、`tags`、`summary`。可以直接交给你的智能体读取、筛选和引用。

## 它怎么工作

```
抓取 / 手动导入 → 关键词分级（影像设备 > 医疗器械 > 背景）+ 主题标签 → 去重存档 → 周报 · 月报 · 网页 · 导出
```

- 分级和标签规则全部写在 `config.json`，可以直接改。
- 所有条目存在 `data/items.json`，周报和月报只是同一份数据的不同时间窗口。
- `.github/workflows/radar.yml` 让 GitHub 每周一自动运行一次自动抓取部分，并更新网页。

## 目录

```
radar.py            主程序
config.json         搜索词、关键词、标签规则
medreg/             抓取、导入、分级、报告、网页
medreg/web/         网页的样式、脚本和模板
inbox/              手动保存的网页放这里
data/items.json     全部条目
reports/            周报 weekly/、月报 monthly/（Markdown）
docs/               网页（GitHub Pages 从这里发布）
```
